# 6. Glossário e Referências Técnicas

## 6.1 Objetivo

Esta seção reúne os principais termos técnicos utilizados na documentação e apresenta referências oficiais para consulta e aprofundamento.

## 6.2 Glossário

| Termo | Definição |
|---|---|
| API (Application Programming Interface) | Interface que permite a comunicação entre diferentes sistemas. |
| Back-end | Camada responsável pelo processamento das requisições, aplicação das regras de negócio e acesso aos dados. |
| Front-end | Camada responsável pela interface e interação com o usuário. |
| Endpoint | Endereço específico utilizado para acessar uma operação disponibilizada por uma API. |
| HTTP | Protocolo utilizado na comunicação entre clientes e servidores na Web. |
| JSON | Formato textual utilizado para representar e transmitir dados estruturados. |
| Request | Requisição enviada pelo cliente ao servidor. |
| Response | Resposta enviada pelo servidor ao cliente. |
| Query Parameters | Parâmetros enviados na URL para filtrar, pesquisar ou paginar resultados. |
| Path Parameter | Parâmetro inserido no caminho da URL para identificar um recurso. |
| Request Body | Conteúdo enviado no corpo de uma requisição HTTP. |
| Response Body | Conteúdo retornado no corpo de uma resposta HTTP. |
| Serializer | Componente utilizado pelo Django REST Framework para converter e validar dados. |
| ORM (Object-Relational Mapping) | Técnica que permite interagir com bancos relacionais por meio de objetos e modelos da aplicação. |
| CRUD | Sigla para Create, Read, Update e Delete: operações básicas de criação, leitura, atualização e exclusão. |
| LGPD | Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018). |
| HTTP Status Code | Código numérico que indica o resultado do processamento de uma requisição HTTP. |
| Paginação | Técnica que divide grandes conjuntos de resultados em páginas menores. |
| Empty State | Estado da interface apresentado quando uma consulta válida não retorna resultados. |
| Loading | Estado visual que indica que uma operação está em andamento. |
